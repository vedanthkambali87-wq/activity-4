# ArenaPass

A responsive, dependency-free football ticketing site with upcoming fixtures,
team and venue listings, a ticket selector, and internal login and signup pages.

## Run locally

Open `index.html` in a browser. The booking and account forms demonstrate
client-side validation and confirmation only; they do not save bookings,
process payments, or create accounts. The fixture schedule and ticket prices
are sample content.

## Pages

- `index.html` — Fixtures, teams, venues, and ticket booking
- `login.html` — Login form
- `signup.html` — Signup form
